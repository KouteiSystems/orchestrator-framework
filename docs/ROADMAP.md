# Roadmap

## 0.1 — supervised framework

Docs, templates, adapters, pinned adoption, and tabletop conformance.

## 0.2 — executable local reference controller

Formal schemas, append-only ledger, validated state transitions, stable run/attempt/turn identities, idempotency, permission brokerage, postconditions, crash recovery, deterministic cleanup, and executable conformance.

## 0.3 and later — certified distribution and transports

Worktree/session launchers, packaged skills or plugins, native host transports, and sandbox-only typed external adapters. Each adapter must publish its capability limits and pass conformance before promotion.

No milestone implies unattended production authority.
