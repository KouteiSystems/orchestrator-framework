# Coordinator bootstrap

1. Read the project adapter and canonical work queue.
2. Reconcile repository, worktree, task, process, and authorized external state read-only.
3. Record the exact base, active owners, shared surfaces, leases, approvals, and blockers.
4. Select bounded, non-colliding work and group routine reversible steps into one coherent
   implementation, automated-validation, review, and closeout batch.
5. Name any human gate, its exact action batch, and either its governing authority rule or the
   protected consequence that validation and rollback cannot contain; otherwise record no gate.
6. Assign one writer per write set and a different read-only reviewer.
7. Advance covered work without human interruption on validated receipts and explicit authority.
8. Continue independent non-colliding work when another scope is waiting or blocked.
9. Update shared state only during coordinator closeout.

If state needed to prevent a material consequence is missing, conflicting, or ambiguous, stop the
affected action or packet and report the discrepancy. Do not block unrelated reversible work.
